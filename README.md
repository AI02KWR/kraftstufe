# Kraftstufe

Krafttraining mit Progressive Overload, Push-Pull-Legs-Plan, XP, Serien und Rängen von Bronze bis Elite.

## Auf dem iPhone installieren
1. Die GitHub-Pages-Adresse der App in **Safari** öffnen (z. B. `https://DEIN-NAME.github.io/kraftstufe/`).
2. Unten auf das **Teilen-Symbol** tippen.
3. **„Zum Home-Bildschirm“** wählen und bestätigen.
4. Kraftstufe startet jetzt vom Home-Bildschirm im Vollbild wie eine App und funktioniert auch offline.

## Daten
Alle Trainings werden nur auf dem Gerät gespeichert. Im Tab **Profil → Datensicherung** kannst du
ein Backup exportieren (z. B. in die Dateien-App) und auf einem anderen Gerät wieder importieren.

## Updates
Änderungen an `index.html` committen und auf `main` pushen. GitHub Actions veröffentlicht sie
automatisch. Vorher `VERSION` in `sw.js` erhöhen. Auf dem iPhone die App einmal schließen und
neu öffnen, dann lädt sie die neue Version.
